## ⚙️ Getting Started

### Prerequisites
- Node.js 18+
- npm or bun

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kunal-sabale10/Portfolio.git
   cd Portfolio/next-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev -- -p 3008
   ```
   Open [http://localhost:3008](http://localhost:3008) in your browser.

4. **Create a production build:**
   ```bash
   npm run build
   ```
